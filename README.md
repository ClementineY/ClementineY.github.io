# Clementine Yang Academic Website

A dependency-free academic website prototype for GitHub Pages, modeled after a
minimal personal research site.

## Files

- `index.html`: homepage with name, short research description, and section links
- `research/index.html`: research interests, publications, preprints, and writing
- `talks/index.html`: upcoming and past talks
- `blog/index.html`: placeholder for posts and notes
- `about/index.html`: bio, contact, and academic links
- `styles.css`: lightweight responsive academic styling
- `favicon.svg`: simple site icon

## Customize

1. Replace the placeholder research field, appointment, publications, talks, and email.
2. Add real links for Google Scholar, ORCID, CV, PDFs, DOI pages, and preprints.
3. Publish from the `main` branch with GitHub Pages.

The current design is static, so there is no build step. Open `index.html`
directly or serve the folder with any local static server.
